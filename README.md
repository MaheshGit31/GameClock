# ⏰ GameClock — The Game-Powered Alarm Clock

> **"Imagine having to play a random game just to snooze your clock! Well… you don't have to imagine that anymore."**

**GameClock** is an alarm clock made to make you stop hitting SNOOZE!.

---

## 📸 Overview & Design

GameClock has a bunch of cool stuff with a cool firmware. Stuff's below.

```text
                    +-----------------------+
                    |    0.96" / 1.3" OLED  |
                    |    Display Header     |
                    +-----------+-----------+
                                |
 +---------------+  +-----------+-----------+  +---------------+
 |  Mechanical   |--|  XIAO ESP32-C3 Board  |--| Active Buzzer |
 |  Switches (4) |  |   (Core Controller)   |  | (Audio Alarm) |
 +---------------+  +-----------------------+  +---------------+


```
